# Netflix Movies and TV Shows Data Analysis

## Project Description

This project focuses on analyzing the **Netflix Movies and TV Shows** dataset using the R programming language. The analysis explores the available data and presents useful insights through data processing and visualization.

## Objective

The main objective of this project is to analyze the Netflix dataset using R and understand different characteristics and trends related to movies and TV shows available on Netflix.

## Tools and Technologies Used

* **R**
* **RStudio**
* **R Markdown**
* **ggplot2**
* **dplyr**

## Dataset

The project uses the **Netflix Movies and TV Shows** dataset stored in:

`netflix_titles.csv`

## Project Files

| File                                             | Description                                    |
| ------------------------------------------------ | ---------------------------------------------- |
| `netflix_titles.csv`                             | Dataset used for the analysis                  |
| `Netflix Movies and TV Shows Data Analysis.Rmd`  | R Markdown source file containing the analysis |
| `Netflix Movies and TV Shows Data Analysis.html` | Generated HTML report of the analysis          |
| `README.md`                                      | Description and documentation of the project   |

## Analysis

The project uses R to process and analyze the Netflix dataset. Data visualization is used to present the results and make the findings easier to understand.
